Realisasi Pengiriman CP-Rembang

Seluruh surat perintah jalan (SPJ) yang keluar dari plant, lengkap dengan waktu antri, waktu proses di pabrik, muatan aktual, dan tujuan.

Tambah data

Impor file Excel (.xls atau .xlsx) berformat sama dengan file realisasi, lalu tarik ke sini atau pilih file. SPJ yang sudah ada dilewati. Data impor hanya tersimpan di browser ini.

    Kedatangan truk per jam

    Jumlah truk yang masuk plant (kolom Masuk) pada tiap jam. Mengikuti filter di atas.

    ZakCurah

    Tonase per produk

    Ton. Arahkan kursor untuk jumlah truk dan zak.

    Tipe truk

    Jumlah SPJ dan rata-rata tonase per truk dan kisaran berat timbangan.

    Peta tujuan pengiriman

    Sebaran tujuan per kota/kabupaten. Jumlah truk tampil di dalam lingkaran, tonase pada label. Peta bersifat skematis: garis pantai dan batas provinsi disederhanakan, posisi titik mengikuti pusat kota/kabupaten.

    Daftar tujuan

    Urut sesuai ukuran lingkaran. Truk dan ton per kota/kabupaten.

    Waktu layanan

    Tunggu = dari antri sampai masuk plant. Proses = dari masuk plant sampai keluar. Median dipakai agar beberapa truk yang antri sejak hari sebelumnya tidak menggeser angka.

    Distribusi waktu proses di pabrik

    Jumlah truk per rentang menit, masuk sampai keluar.

    Distribusi waktu tunggu

    Jumlah truk per rentang menit, antri sampai masuk.

    Median waktu tunggu per jam masuk

    Jam saat truk masuk plant. Jam dengan antrean panjang tampak lebih tinggi.

    Data SPJ

    Semua baris sesuai filter. Klik judul kolom untuk mengurutkan.

    Total tonase = jumlah kolom TONNAGE per DO. Berat timbangan = berat isi dikurangi berat kosong; dua truk dengan dua DO pada satu penimbangan dibagi sesuai tonase DO agar tidak terhitung ganda. Jumlah truk dihitung per penimbangan (232 truk untuk 234 SPJ), dan statistik waktu memakai satu baris per truk. Waktu tunggu yang bernilai negatif (5 baris, truk tercatat masuk sebelum antri) dihitung 0. Nama distributor dan ekspeditur dipotong pada 35 karakter di file sumber.

    Display Conveyor (Realtime)

    Monitoring posisi tiap conveyor secara langsung (realtime) dari SIG Intransit (https://app.sig.id/sgg/sd/intransit/index.php/dashboard): truk yang sudah di dalam plant (loading) dan truk antri yang sudah booking conveyor.

    Terhubung ke SIG Intransit (Realtime)

    ℹ️ Pengambilan Data Realtime dari https://app.sig.id/sgg/sd/intransit

    Browser membatasi pengambilan data antar-domain (CORS) bila file ini dibuka langsung secara lokal (file:///...). Pilih salah satu solusi termudah:

    1. Jalankan Proxy Otomatis (Direkomendasikan): Klik ganda file jalankan-realtime.bat di folder Downloads. File ini langsung membuka browser dan menyalurkan data SIG secara otomatis tanpa hambatan CORS.
    2. Pasang Ekstensi Browser: Pasang ekstensi "Allow CORS: Access-Control-Allow-Origin" di Chrome/Edge, lalu aktifkan saat membuka dashboard.
    3. Buka Chrome Bebas CORS: Jalankan perintah: chrome.exe --disable-web-security --user-data-dir="%TEMP%\chrome_sig".
    4. Gunakan Proxy Kustom: Masukkan alamat proxy relay Anda:
